Which editor experience do you want?

The current draft editor is a raw markdown textarea. A rich text editor lets you format inline and see the result immediately.

A

Rich text WYSIWYG editor

Full What-You-See-Is-What-You-Get editor with toolbar (bold, italic, headings, links, lists). Edits HTML/Markdown under the hood. Like Medium or Notion.

B

Split-pane: markdown + live preview

Two panes side by side — edit markdown on the left, see the rendered output on the right in real-time. Like a code editor with live preview.

C

Keep markdown, add a preview toggle

Same markdown textarea but with a "Preview" button that shows the rendered output. Toggle between edit and preview modes. Lightest change.
